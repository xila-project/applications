# Digits implementation plan

Goal: a bounded MNIST drawing guest exercising the existing NN VFS ABI on Xila desktop and web.

The user approved the drawing/recognition proposal and asked to reuse Paint. Use Rust, Pixel Painter drawing and viewport code, and the generic WASI fd_control extension. Keep models and application UI in Applications; runtime model registration and backend selection belong in Platforms. No changes to Core's ABI are needed. Keep the original checkout intact and work on separate submodule branches in the isolated workspace.

- [x] Add preprocessing/ranking tests, observe failure, implement crop/area-resize/normalization and reject blank or invalid scores.
- [x] Train a deterministic small float MLP on the MNIST training split; retain dataset/model hashes, held-out accuracy and exporter. Keep training dependencies out of builds.
- [x] Build the Wasm UI using existing indexed canvas and strokes, clear/undo, automatic recognition on release, and explicit retry/error states. Derive command identifiers and tensor metadata from Core.
- [x] Register the aligned model in Platforms native/browser runtime assemblies; test actual model inference through the VFS using held-out samples.
- [x] Add guest build/check/release metadata and optional local bundle seeding before the first release.
- [x] Run application suite, guest builds, platform checks, seed tests, workflow validation and native Debug UI validation; document exact commands and limits.

Review focus: letterboxing and resizing; blank/tiny/edge strokes; incompatible/missing NN device; repeated inference cursor/completeness; scores are probabilities rather than calibrated confidence; default browser dependency features and model ownership; clean lockfiles without local source patches.

Execution notes: baseline Pixel Painter suite passed (6 tests). New preprocessing/ranking tests failed with the initial stubs, then passed (3 tests). The platform VFS test initially expected each selected sample to be classified correctly. Independent NumPy evaluation established the selected 5 is predicted as 8; retain the sample and pin that oracle result instead of claiming perfect accuracy. Model test accuracy is 96.97% on the untouched 10,000-image test set, not on freehand input.

Validation: standalone locked guest check, all seven release Wasm builds, full Applications workspace test suite, manifest/policy/localization checks and workflow/TOML/Rust formatting passed. Platform portable VFS and shared-driver suites, seed suite and optional-local-bundle regression passed; native and browser runtime builds passed, as did Clippy for Digits and changed platform crates. Native headless Debug test launched the final bundle, drew a vertical stroke, observed Digit 1 with top-three scores, and cleared the canvas. Rebooting the same disk first reproduced AlreadyExists; startup now tolerates the persisted NN directory and cleans stale device nodes. The existing Debug directory had the same issue and received the same narrow fix. Recognition worked after reboot. Browser execution and physical hardware were not exercised. No workspace gitlink is repinned to these unmerged changes.
